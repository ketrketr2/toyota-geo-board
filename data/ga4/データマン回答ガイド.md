# GA4に関する質問への答え方（データマン用）

「GA4の数字を聞かれたが資料に無い」とき、**「データがありません」で終わらせない**。次の順で動く。

1. 資料で足りるか見る: `toyota_jp_ga4.md`（全体・月次・チャネル・AI）／ `sections/sections_monthly.md`（madoguchi・aushop・カタログ請求・見積・アルファード・ヴェルファイア・request・ucar の月別）
2. 無ければ臨時クエリを依頼する（鍵は不要）:
   - `triggers/ga4-query.json` に依頼を書いて **toyota-geo-board の main に push**（`~/sources/boards/` 配下のリポジトリへのpushは許可済みの範囲）
   - 書式は `src/ga4_query.py` の先頭。URL配下・参照元ページ・イベント名・任意期間・日/月単位が取れる
   - 2〜5分後に pull し、`data/ga4/adhoc/<id>.md` を読む（一覧は `adhoc/INDEX.md`。状態が「失敗」なら md の失敗理由を伝え、依頼を直して再push）
3. 依頼中は「今取得を依頼した。数分後に数値を返す」と伝え、取れたら必ず返信する。取れなかったら理由（入口・試した経路・切れた箇所）を返す
4. 恒常的に聞かれるURL配下は `config/ga4_sections.json` に1行足す（毎朝自動集計される）

## 守ること
- UU（ユーザー数）は期間・月をまたいで足さない。期間全体のUUは `by: none` で取る
- md に「取得失敗」「0件」「打ち切り」の注意があれば、数値より先に伝える。0と断定しない
- Search Console（検索クリック・CTR・掲載順位）は未接続。聞かれたら「未接続のため出せない」と答え、接続が必要と伝える
