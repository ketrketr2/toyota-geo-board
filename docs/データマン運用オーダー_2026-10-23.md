# データマン運用オーダー（2026-10-23）答えられない質問の再発防止

対象: Mac mini 上のデータマン（toyota-dataman）。CLAUDE.md の変更は「変更前→変更後」をけんけんさんに見せて許可を得てから反映する。

## 1. 先に pull（toyota-geo-board）
- `data/ga4/データマン回答ガイド.md` を kb に取り込む（GA4質問は最初にこれを見る）
- `data/ga4/sections/sections_monthly.md`（madoguchi・aushop・request・見積・アルファード・ヴェルファイア・ucar の月別）を kb に取り込む
- `data/ga4/adhoc/INDEX.md` と各 `<id>.md`（臨時クエリの結果）も取り込む

## 2. CLAUDE.md への追記案（変更前→変更後。変更前は「GA4はkb内の資料のみ」系の記述）
変更後（追記）:
> GA4の数字が資料に無いときは「データなし」で終えない。toyota-geo-board の `triggers/ga4-query.json` に依頼を書いて main に push する（~/sources/boards/ 配下なので push 許可の範囲）。2〜5分後に pull して `data/ga4/adhoc/<id>.md` を読み、数値を返す。依頼中は「取得を依頼した、数分後に返す」と先に伝える。
> 取れなかった場合は ①入口 ②試した経路 ③切れた箇所 を返す。
> UUは期間・月をまたいで足さない。Search Console（検索クリック・CTR）は未接続なので出せないと答える。

## 3. 答えられなかった質問の記録（再発の検知）
- 答えきれなかった質問は `kb/_gaps.jsonl` に1行（日時・質問・原因分類 A=資料に無い B=GA4切り口 C=長文切れ D=添付読めず E=認証/鍵・対応状況）で追記する
- 毎朝のダイジェストに「未解決の答えられなかった質問 N件／最古 YYYY-MM-DD」を1行入れる。7日以上残っているものは赤字扱いで先頭に出す

## 4. ボード・添付の取りこぼし防止
- `kb/_boards.md` に「ボード名／URL／取り込み状態（済・認証要・暗号化・外部WS）／最終取り込み日」を一覧で持つ。boards_sync.py は一覧に無いボードを検知したらDMする
- ROOMY AIO は閲覧画面がログイン要・データ暗号化のため、URLを開いても本文が取れない。復号して取り込む手順を決めるか、本人から元データをもらう運用にし、_boards.md に「認証要」と明記して、聞かれたら「取り込めていない理由と必要なもの」を返す
- 外部Slackワークスペースの資料・画像添付は、読めない場合に「読めなかった」と必ず返す（黙って推測しない）

## 5. 長文回答の切れ防止
- 回答が長いときは、結論→根拠→詳細の順に分割して複数投稿し、最後に「以上で完結」を付ける。末尾が途中で切れた投稿を検知したら続きを自動投稿する
