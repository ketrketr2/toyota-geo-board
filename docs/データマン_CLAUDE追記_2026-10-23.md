## ボード（ID/PW付きダッシュボード）の質問
- 該当ボードは `kb/boards/_boards.md`（ボード台帳）で特定し、`kb/boards/<フォルダ>/README.md` → `画面本文.md` の順に読む。画面に無い集計は同じフォルダの `data_*.json` から計算してよい（その場合は「ボードの元データから集計」と明記）
- 「含まれていない」「見られない」「そのボードは知らない」と答える前に、`kb/boards/` を必ず検索する（grep）。ROOMY AIO の設問一覧は `kb/boards/roomy_aio/設問一覧.md`
- 資料の鮮度は `kb/boards/_取り込み状況.md` で確認する。「失敗」または古い場合は、その旨を回答の先頭で伝える
- 「ルーミーダッシュボード」が ROOMY AIO と ROOMY COMMAND のどちらか曖昧なら、両方を確認して答え、どちらの数値かを明記する
- 車種別AI分析・CAR×AI SIGNAL の AI指標は「計測回」の値（README の更新欄に計測回の日付がある）。日次の値ではないので、日付を添えて答える

## GA4 の質問
- `~/sources/boards/toyota-geo-board/data/ga4/データマン回答ガイド.md` に従う。資料に無い切り口（URL配下・参照元ページ・任意期間など）は臨時クエリ（`triggers/ga4-query.json` を push）で取り、数分後に数値を返す。「データがありません」で終えない
- 主要URL配下の月別は `data/ga4/sections/sections_monthly.md`、臨時クエリの結果は `data/ga4/adhoc/`
- UU（ユーザー数）は期間・月をまたいで足さない
- Search Console（検索クリック・CTR・掲載順位）は未接続。聞かれたら「未接続のため現時点では出せない。接続すれば取得できる」と答える

## 添付ファイル（画像・PDF・Excel・PowerPoint）
- 質問に添付されたファイルは、`.env` のユーザートークンで `files.info` → `url_private_download` から `/tmp` に取得して中身を読む（画像は Read で見る。PDF・Excel・PowerPoint はテキストを抽出する）。トークンは表示しない。取得してよいのは、その質問に添付されたファイルIDだけ
- 取得・読み取りに失敗したら「添付を読めなかった（理由）」と明記する。推測で中身を補わない

## 長い回答
- 回答が長くなるときは「結論 → 根拠 → 詳細」の順に分けて複数投稿し、最後の投稿の末尾に「以上」と書く。途中で切れた投稿があれば続きを投稿する

## 答えられなかった質問の記録（再発の検知）
- 答えきれなかった質問は `kb/_gaps.jsonl` に1行で追記する: `{"ts": ISO日時, "from": 質問者, "q": 質問, "cause": "A資料に無い|Bデータの切り口|C長文切れ|D添付読めず|E認証・鍵", "status": "open"}`
- 解決したら `status` を `closed` にし、`fix` に解決方法を書く
- 日次ダイジェストに「未解決の答えられなかった質問 N件（最古 YYYY-MM-DD）」を1行入れる。7日以上 open のものは先頭に出す
